## The path of one row

1. An order is inserted or updated in the source Postgres database.
2. Every ten minutes, Airflow starts a sync for the window that just closed.
3. Spark reads that window from Postgres in parallel slices, one per executor task.
4. Spark merges the rows into an Iceberg table on `id`, so a rerun gives the same result.
5. Iceberg writes data files to RustFS and records a new snapshot in the REST catalog.
